# 6강. 생성형 AI 서비스의 기초

- 학습일: 2026-08-21
- 과목: AI네이티브가되기위한기초소양
- 주제: ChatGPT, Gemini, Claude의 특징과 모델 선택 기준

## 핵심 요약

생성형 AI 서비스는 LLM, 이미지 생성 모델, 음성 생성 모델 같은 생성형 AI 모델에 대화 화면, 파일 업로드, 음성 입력, 외부 서비스 연동 기능을 붙여 누구나 쉽게 사용할 수 있게 만든 서비스다. 대표적인 텍스트 기반 서비스로 ChatGPT, Gemini, Claude가 있으며, 각 서비스는 개발 방향과 생태계에 따라 서로 다른 강점을 가진다.

## 생성형 AI 서비스란

생성형 AI 모델은 텍스트, 이미지, 영상, 음성 등을 생성할 수 있는 기반 기술이다. 여기에 사용자가 쉽게 명령을 입력하고 결과를 확인할 수 있는 인터페이스가 결합되면 생성형 AI 서비스가 된다.

| 유형 | 대표 서비스 |
| --- | --- |
| 텍스트 기반 | ChatGPT, Gemini, Claude |
| 이미지 생성 | Midjourney, Adobe Firefly |
| 영상 생성 | Runway, Google VEO |
| 음성 생성 | Suno, ElevenLabs |

이번 강의는 텍스트 기반 생성형 AI 서비스인 ChatGPT, Gemini, Claude를 중심으로 다룬다.

## 서비스별 특징

| 서비스 | 개발사 | 주요 특징 |
| --- | --- | --- |
| ChatGPT | OpenAI | 맞춤형 GPT 제작, GPT Store, Apps 연동 |
| Gemini | Google | Gmail, Drive, Photos, Maps, Search 등 Google 서비스 연동 |
| Claude | Anthropic | 헌법 AI 기반의 안전성, Artifact, 컴퓨터/외부 서비스 작업 |

## ChatGPT

ChatGPT는 OpenAI가 2022년 11월 출시한 대화형 AI 서비스다. GPT-3.5를 시작으로 다양한 GPT 모델을 제공하며, 사용자가 특정 목적에 맞는 맞춤형 챗봇을 만들 수 있는 GPTs 기능을 지원한다.

### GPTs

GPTs는 ChatGPT를 특정 목적에 맞게 커스터마이징한 맞춤형 AI 앱이다.

- 자연어 지시만으로 제작 가능
- 역할, 응답 방식, 금지사항, 출력 형식 지정 가능
- 대화 스타터를 통해 자주 쓰는 질문 버튼 제공
- 링크 공유 또는 GPT Store 등록 가능

예를 들어 주식 리서치 파트너 GPT를 만들면 최신 주식 동향, 거시 환경, 주요 리스크, 대표 기업 분석 등을 정해진 형식으로 정리하도록 설정할 수 있다.

### Apps

Apps는 ChatGPT를 외부 서비스와 연결하는 기능이다. 외부 앱의 데이터를 대화 안에서 바로 활용할 수 있다.

예시:

- Apple Music에서 플레이리스트 검색
- 연결된 서비스의 데이터 조회
- 앱별 기능을 ChatGPT 대화창에서 실행

## Gemini

Gemini는 Google의 생성형 AI 서비스다. 2023년 3월 Bard로 출시되었고, 2024년 2월 Gemini로 이름이 변경되었다. Google 생태계와의 연동성이 강점이다.

### Google 서비스 연동

| 연동 서비스 | 활용 예시 |
| --- | --- |
| Gmail | 조건에 맞는 메일 검색, 미회신 메일 확인 |
| Google Drive | 관련 문서 검색 |
| Google Photos | 사진 분석, SNS 캡션 작성 |
| Google Maps | 장소 추천, 경로 안내 |
| Google Search | 최신 정보 검색 및 요약 |

Gemini는 단순 키워드 검색이 아니라 문맥을 바탕으로 정보를 찾을 수 있다. 예를 들어 납기 지연이나 품질 클레임처럼 표현이 다양할 수 있는 메일도 의미를 기준으로 찾아 정리할 수 있다.

## Claude

Claude는 Anthropic의 생성형 AI 서비스다. Anthropic은 AI가 지켜야 할 행동 원칙을 기준으로 답변을 검토하고 수정하는 헌법 AI 접근을 강조한다.

### 헌법 AI

헌법 AI는 AI가 사전에 정의된 원칙을 바탕으로 자신의 답변을 점검하고 개선하도록 학습시키는 방식이다.

주요 방향:

- 특정 집단에 대한 차별적 표현을 피한다.
- 사실이 아닌 내용을 사실처럼 말하지 않는다.
- 유해하거나 위험한 답변을 줄인다.
- 근거 있는 정보를 선별해 답변한다.

### Artifact

Artifact는 Claude가 생성한 결과물을 별도 창에서 미리 보여주는 기능이다.

- 문서 생성 및 수정
- 코드 결과 확인
- 웹페이지 레이아웃 확인
- 디자인 결과 검토
- 다운로드 가능한 문서 생성

대화는 왼쪽에서 이어가고, 오른쪽에서 결과물을 바로 확인하며 수정할 수 있다는 점이 장점이다.

### Cowork와 Connector

Claude는 로컬 파일이나 외부 서비스와 연동해 실제 작업을 수행할 수 있다.

예시:

- 사진 속 대상을 판별해 파일명 변경
- 영수증 이미지를 분석해 엑셀 파일로 정리
- Figma와 연동해 카드 뉴스 디자인 생성
- Notion, Slack, Google Calendar 등 외부 서비스 연결

## 모델 선택 기준

같은 서비스 안에서도 선택 가능한 모델이 여러 개다. 작업 목적에 맞는 모델을 고르려면 다음 기준을 고려해야 한다.

| 기준 | 의미 | 선택 방향 |
| --- | --- | --- |
| 속도 | 답변 생성에 걸리는 시간 | 간단한 작업은 작은 모델이 효율적 |
| 정보량 | 한 번에 처리해야 하는 문서의 양 | 긴 문서는 컨텍스트 윈도우가 큰 모델 필요 |
| 경제성 | 입력/출력 토큰 비용 | 반복 작업은 비용 대비 성능 고려 |
| 작업 유형 | 추론, 코딩, 이미지, 음성 등 | 작업에 강한 모델 선택 |

## 모델 크기와 성능

모델의 파라미터 수가 많을수록 일반적으로 복잡한 작업에서 더 높은 성능을 보이지만, 답변 생성 속도는 느려지고 비용은 증가할 수 있다.

| 모델 크기 | 특징 | 적합한 작업 |
| --- | --- | --- |
| 대형 모델 | 높은 추론 성능, 느린 속도, 높은 비용 | 복잡한 분석, 어려운 문제 해결 |
| 중형 모델 | 성능과 속도의 균형 | 일반 업무, 요약, 문서 작성 |
| 소형 모델 | 빠른 속도, 낮은 비용 | 간단한 질문, 대량 반복 처리 |

## 컨텍스트 윈도우

컨텍스트 윈도우는 LLM이 한 번에 읽고 처리할 수 있는 텍스트의 양이다. 긴 문서, 여러 파일, 대화 기록을 함께 다뤄야 하는 작업에서는 컨텍스트 윈도우가 큰 모델이 유리하다.

모델별 컨텍스트 크기와 가격은 계속 바뀔 수 있으므로 실제 사용 시점의 최신 정보를 확인해야 한다.

## 비용 구조

AI API는 보통 입력 토큰과 출력 토큰에 각각 비용이 부과된다. 출력 토큰은 입력 토큰보다 비싼 경우가 많기 때문에 긴 보고서나 장문의 콘텐츠를 반복 생성할 때는 비용 차이가 커질 수 있다.

비용을 줄이려면 다음을 고려한다.

1. 간단한 작업은 소형 또는 중형 모델을 사용한다.
2. 복잡한 추론이 필요한 단계에만 대형 모델을 사용한다.
3. 출력 형식을 명확히 지정해 불필요한 장문 생성을 줄인다.
4. 반복 업무에서는 정확도와 비용을 함께 비교한다.

## 정리

ChatGPT, Gemini, Claude는 모두 생성형 AI 서비스지만 강점이 다르다. ChatGPT는 맞춤형 GPT와 앱 생태계, Gemini는 Google 서비스 연동, Claude는 Artifact와 외부 작업 수행 기능이 두드러진다. 실제 업무에서는 서비스 이름보다 작업 복잡도, 입력 정보량, 속도, 비용을 기준으로 적합한 모델을 선택하는 것이 중요하다.
