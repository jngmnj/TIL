# 8강. 생성형 AI 서비스를 활용한 데이터 분석

- 학습일: 2026-08-29
- 과목: AI네이티브가되기위한기초소양
- 주제: 데이터 전처리, 분석 수행, 분석 환경 세팅, AI 분석 결과 검토

## 핵심 요약

기존 데이터 분석은 엑셀, 파이썬, SPSS처럼 도구별 사용법과 문법을 익히고, 데이터 정리부터 오류 수정과 결과 해석까지 사용자가 직접 수행해야 했다. 생성형 AI 서비스를 활용하면 자연어 프롬프트만으로 데이터 정리, 분석, 시각화, 해석, 대시보드 생성까지 수행할 수 있다.

다만 AI는 주어진 데이터의 패턴을 바탕으로 분석하므로, 데이터 밖의 맥락이나 통계적 한계를 자동으로 완전히 보정하지는 못한다. 따라서 사용자는 분석 목표와 업무 맥락을 제공하고, 결과를 비판적으로 검토해야 한다.

## 기존 데이터 분석 도구

데이터 규모와 분석 목적에 따라 다양한 도구가 사용되어 왔다.

| 도구 | 특징 |
| --- | --- |
| Excel | 코딩 없이 소규모 데이터 계산과 시각화 가능 |
| Python | 대규모 데이터 가공, 분석, 시각화에 적합 |
| SPSS | 통계적 유의성 검증, 설문 분석, 학술 연구에 특화 |

이 도구들은 강력하지만 사용자가 수식, 코드, 통계 개념, 오류 수정 방법을 직접 알아야 한다는 부담이 있다.

## 기존 방식의 어려움

기존 데이터 분석 과정에서 사용자가 직접 처리해야 했던 단계는 다음과 같다.

| 단계 | 어려움 |
| --- | --- |
| 데이터 수집 및 정리 | 날짜 형식 통일, 빈칸 제거, 파일 통합 등을 직접 수행 |
| 수식과 코드 작성 | 도구마다 다른 문법과 함수 학습 필요 |
| 오류 수정 및 재실행 | 수식 오류, 범위 누락, 코드 에러를 직접 찾아 수정 |
| 결과 해석 | 통계 출력값과 그래프의 의미를 스스로 판단 |

이러한 부담은 데이터 분석 비전문가에게 큰 진입장벽이 된다.

## AI를 활용한 데이터 분석의 변화

생성형 AI 서비스를 활용하면 실행 작업은 AI가 대신 수행하고, 사용자는 분석 목적과 결과 해석에 더 집중할 수 있다.

```text
기존 방식: 데이터 정리 -> 코드 작성 -> 오류 수정 -> 그래프 생성 -> 해석
AI 활용: 자연어 질문 -> AI가 분석 수행 -> 결과와 해석 확인
```

예를 들어 “이 고객 데이터에서 주목해야 할 패턴이나 특이한 점을 알려줘”라고만 입력해도 AI는 구매 금액 분포, 연령대별 차이, 특정 고객군의 존재 여부처럼 분석 방향을 스스로 정할 수 있다.

## 생성형 AI의 데이터 분석 활용 영역

생성형 AI는 데이터 분석 과정에서 크게 세 가지 영역에 활용된다.

| 활용 영역 | 설명 |
| --- | --- |
| 데이터 전처리 | 분석 가능한 형태로 데이터 정리와 가공 |
| 분석 수행 | 패턴 발견, 원인 탐색, 인사이트 도출 |
| 분석 환경 세팅 | 반복 활용 가능한 대시보드나 분석 환경 구축 |

각 영역은 단독으로도 활용할 수 있고, 하나의 업무 흐름으로 연결할 수도 있다.

## 데이터 전처리

데이터 전처리는 데이터를 분석에 활용할 수 있는 형태로 정리하고 가공하는 과정이다.

실무 데이터는 다음처럼 바로 분석하기 어려운 경우가 많다.

| 문제 | 예 |
| --- | --- |
| 파일 형식 차이 | 어떤 지점은 CSV, 다른 지점은 Excel로 제출 |
| 컬럼명 차이 | `매출액`, `매출 금액`, `실적 금액`이 같은 의미로 사용 |
| 단위 차이 | 원, 만원, 천원이 섞여 있음 |
| 맥락 누락 | 지점명, 행사 여부, 환율 등 분석에 필요한 정보 부족 |

AI는 여러 파일의 구조를 읽고 컬럼명과 단위를 통일한 뒤 하나의 데이터셋으로 합칠 수 있다.

## 실습: 지점별 매출 파일 통합

서울, 부산, 대구 지점의 분기 매출 파일을 하나로 합치는 상황을 생각해보자.

| 지점 | 컬럼명 | 금액 단위 | 카테고리 컬럼 |
| --- | --- | --- | --- |
| 서울 | `매출액` | 원 | `제품 카테고리` |
| 부산 | `매출 금액` | 만원 | `분류` |
| 대구 | `실적 금액` | 천원 | `카테고리` |

요청 예시는 다음과 같다.

```text
이 세 파일은 각 지점의 이번 분기 매출 데이터야.
파일마다 컬럼 이름과 금액 단위가 다르니 형식을 원 단위로 통일해서 하나로 합쳐줘.
그리고 지점별 매출 합계와 제품 카테고리별 순위를 알려줘.
```

AI는 컬럼 의미를 파악하고, 금액을 원 단위로 변환하며, 어느 지점의 데이터인지 알 수 있도록 지점 컬럼을 추가할 수 있다.

## 내부 데이터와 외부 데이터 결합

분석 품질을 높이려면 원본 데이터에 포함되지 않은 맥락 정보를 결합해야 할 때가 있다.

예를 들어 매출 데이터에 다음 정보를 추가할 수 있다.

| 결합 데이터 | 활용 목적 |
| --- | --- |
| 사내 행사 캘린더 | 행사 기간과 매출 변화의 관련성 확인 |
| 광고 집행 이력 | 프로모션 효과 분석 |
| 환율 데이터 | 해외 매출이나 원가 변동 해석 |
| 공공 API 데이터 | 날씨, 물가, 환율 등 외부 변수 반영 |

커넥터 기능을 사용하면 Google Drive, Google Calendar, 외부 API 등을 연결해 AI가 직접 데이터를 읽고 결합할 수 있다.

## 실습: 행사 여부와 환율 컬럼 추가

통합 매출 파일에 사내 행사 정보를 결합하는 요청은 다음처럼 작성할 수 있다.

```text
내 구글 드라이브의 통합 매출 2026 Q1 파일이야.
각 거래일자별로 우리 회사 사내 행사 캘린더에 해당 날짜 일정이 있었는지를
행사 여부 컬럼으로 추가해서 보여줘.
```

이후 외부 환율 데이터를 추가할 수도 있다.

```text
앞선 결과 데이터에 그날의 달러 원화 환율을 환율 컬럼으로 결합해서 새 파일로 만들어줘.
환율은 한국은행 데이터를 출처로 사용해줘.
```

이처럼 AI는 내부 데이터와 외부 데이터를 결합해 분석 맥락을 확장할 수 있다.

## 분석 수행의 3단계

데이터 분석은 크게 세 단계로 진행된다.

| 단계 | 핵심 질문 | 설명 |
| --- | --- | --- |
| 문제 인식 | 무슨 일이 발생했는가? | 데이터에서 변화, 패턴, 이상치를 찾음 |
| 원인 탐색 | 왜 발생했는가? | 어떤 요인이 결과에 영향을 주었는지 확인 |
| 결과 해석 | 어떻게 해야 하는가? | 분석 결과를 의사결정으로 연결 |

AI는 각 단계에서 질문을 구체화하고, 적절한 분석 방법과 시각화를 제안하며, 결과 해석까지 도와줄 수 있다.

## 문제 인식

문제 인식은 데이터에서 눈에 띄는 변화나 반복되는 경향을 찾는 단계다.

대표적인 질문 유형은 다음과 같다.

| 질문 유형 | 예 | 적합한 시각화 |
| --- | --- | --- |
| 순위 비교 | 가장 많이 팔린 제품은 무엇인가? | 막대그래프 |
| 그룹 비교 | 연령대별 구매 비중은 어떻게 다른가? | 그룹별 막대그래프, 누적 그래프 |
| 추세 분석 | 신규 가입자는 언제부터 줄었는가? | 선그래프 |

사용자가 구체적인 분석 항목을 모르더라도 “눈에 띄는 패턴 3가지를 알려줘”처럼 질문하면 AI가 먼저 분석 방향을 제안할 수 있다.

## 원인 탐색

원인 탐색은 발견한 변화나 문제의 원인을 데이터에서 찾는 단계다.

원인 탐색 접근은 크게 두 가지다.

| 접근 | 설명 | 예 |
| --- | --- | --- |
| 요인 간 관계 | 두 항목이 함께 움직이는지 확인 | 할인율이 높을수록 판매 수량이 늘어나는가? |
| 요인 내 차이 | 특정 조건별 결과 차이를 비교 | 담당자별 실적 차이가 있는가? |

어떤 요인을 의심해야 할지 모를 때는 AI에게 가설 수립을 요청할 수 있다.

```text
8월 매출 급증의 원인으로 어떤 변수들을 의심해봐야 할까?
분석 계획을 세워줘.
```

## 결과 해석

결과 해석은 분석 결과를 실제 의사결정으로 연결하는 단계다.

AI에게 다음과 같은 요청을 할 수 있다.

```text
이 분석 결과를 바탕으로 다음 달 영업 전략을 제안해줘.
주의해야 할 리스크도 함께 정리해줘.
실행 우선순위를 로드맵 형태로 만들어줘.
```

예를 들어 특정 지역의 매출이 급증했더라도, 그것이 지속 가능한 성장인지 일회성 대형 거래인지 확인해야 한다. AI는 밀어내기 판매, 예산 앞당김, 외상 결제에 따른 현금흐름 악화 같은 리스크 후보를 제시할 수 있다.

## 실습: 영업 거래 데이터 분석

6개월치 영업 거래 기록을 바탕으로 이번 달 영업 전략 보고서를 만드는 상황을 생각해보자.

데이터에는 다음 항목이 포함된다.

| 컬럼 | 설명 |
| --- | --- |
| 거래 일자 | 거래가 발생한 날짜 |
| 지역 | 거래 지역 |
| 제품 카테고리 | 판매 제품군 |
| 담당자 | 영업 담당자 |
| 거래 금액 | 매출 금액 |
| 거래처 | 고객사 |

분석은 다음처럼 진행할 수 있다.

1. “이 데이터에서 눈에 띄는 패턴이나 특이한 점 3가지를 알려줘.”
2. “8월의 매출 급증 원인을 분석하려면 데이터를 어떻게 쪼개서 봐야 할까?”
3. “8월 지역별 매출을 보여주고, 특정 지역을 카테고리별로 7월과 비교해줘.”
4. “우리 회사는 8월에 프로모션을 한 적이 없고 전자제품은 여름이 비수기야. 그런데도 매출이 늘었다면 무엇을 의심해야 할까?”

이 과정에서 사용자는 업무 맥락을 추가해 AI의 해석 방향을 좁혀갈 수 있다.

## 차트와 해석의 결합

AI는 그래프만 그리는 것이 아니라 그래프가 시사하는 의미까지 설명할 수 있다.

예를 들어 8월 특정 지역에서 소수의 고액 거래가 전체 매출을 끌어올린 경우, AI는 히스토그램이나 박스플롯을 그려 거래 금액 분포를 보여주고 다음과 같이 해석할 수 있다.

```text
소수의 매우 높은 금액 거래가 전체 매출의 상당 부분을 견인했다.
```

이런 해석은 사용자가 단순 평균이나 합계만 보고 놓칠 수 있는 구조를 파악하는 데 도움이 된다.

## Excel 안에서 AI 활용

채팅형 AI는 분석 결과를 대화창에 보여주고, 사용자는 이를 다시 Excel 등에 반영해야 한다. 반면 Excel에 내장된 AI 기능은 현재 열려 있는 파일을 직접 수정할 수 있다.

가능한 작업은 다음과 같다.

| 작업 | 예 |
| --- | --- |
| 데이터 정제 | 날짜 형식 통일, 누락값 확인, 중복 제거 |
| 새 시트 생성 | 정제 데이터, 핵심 지표, 분석 보고서 시트 생성 |
| 수식 입력 | KPI 계산, 평균, 합계, 비율 계산 |
| 차트 삽입 | 막대그래프, 선그래프, 분포 차트 생성 |
| 보고서 작성 | 인사이트와 전략 방향 정리 |

파일 안에서 직접 실행되므로 분석 결과를 옮겨 적는 과정을 줄일 수 있다.

## 실습: 리뷰 데이터 분석 보고서

온라인 쇼핑몰의 화장품 리뷰 약 600건을 분석해 다음 분기 마케팅 방향을 잡는 상황을 생각해보자.

데이터에는 다음 컬럼이 있다.

| 컬럼 | 예 |
| --- | --- |
| 리뷰 ID | 리뷰 식별 번호 |
| 작성일 | 리뷰 작성 날짜 |
| 별점 | 고객 평점 |
| 피부 타입 | 건성, 지성, 복합성 등 |
| 피부 고민 | 트러블, 보습, 진정 등 |
| 리뷰 본문 | 고객이 작성한 텍스트 |
| 사진 포함 여부 | 사진 리뷰 여부 |
| 재구매 언급 | 재구매 의사 표현 여부 |
| 구매 경로 | 유입 채널 |

AI는 날짜 형식이 섞여 있거나 누락값이 있는 문제를 스스로 찾아 정제하고, KPI 카드, 채널 분석, 고객 특성 분석, 키워드 분석 결과를 보고서 형태로 구성할 수 있다.

## 분석 환경 세팅

AI는 일회성 분석뿐 아니라 반복해서 사용할 수 있는 분석 환경도 만들 수 있다.

고정 보고서는 데이터를 다시 분석하려면 매번 프롬프트를 새로 입력해야 한다. 반면 대시보드는 새 데이터가 추가될 때 자동으로 갱신되고, 사용자가 조건을 선택하며 분석 관점을 바꿀 수 있다.

```text
일회성 분석 결과 -> 정적인 보고서
반복 분석 환경 -> 인터랙티브 대시보드
```

## 실습: 광고 성과 대시보드 생성

구글, 네이버, 메타, 카카오 4개 채널의 주차별 광고 성과 데이터를 기반으로 대시보드를 만들 수 있다.

요청 예시는 다음과 같다.

```text
이 폴더의 주차별 광고 성과 데이터 파일을 모두 합쳐서 대시보드를 만들어줘.
상단에는 총 광고비, 총 전환수, 평균 CPA, 평균 CTR KPI 카드를 넣어줘.
채널별 광고비와 전환수를 비교하는 막대그래프,
일자별 전환수 추이 라인 차트,
정렬과 검색이 가능한 데이터 테이블도 포함해줘.
매주 새 파일이 추가되면 다시 열 때마다 자동으로 갱신되도록 해줘.
```

완성된 대시보드는 필터, 기간 선택, 검색, 새로 고침을 통해 사용자가 직접 다양한 관점에서 데이터를 살펴볼 수 있게 한다.

## AI 데이터 분석의 한계

AI는 데이터 패턴을 빠르게 찾지만, 다음 한계를 가진다.

| 한계 | 설명 |
| --- | --- |
| 관계 해석의 오류 | 우연한 상관관계를 의미 있는 관계로 오해할 수 있음 |
| 외부 맥락 누락 | 업계 관행, 계절성, 시장 특성이 데이터에 없으면 반영하지 못함 |
| 성급한 일반화 | 데이터 수가 충분하지 않은데 결론을 일반화할 수 있음 |
| 이상치 영향 | 소수의 극단값 때문에 평균이나 결론이 왜곡될 수 있음 |

AI의 분석 결과는 출발점으로 활용하되, 최종 판단은 사람이 데이터 맥락과 업무 상황을 함께 고려해야 한다.

## 관계 해석 오류 예

아이스크림 판매량과 물놀이 사고 수가 함께 증가하는 그래프가 있다고 하자. AI는 이를 보고 아이스크림 판매가 물놀이 사고를 증가시킨다고 잘못 해석할 수 있다.

하지만 실제 원인은 기온이나 계절일 수 있다.

```text
기온 상승 -> 아이스크림 판매 증가
기온 상승 -> 물놀이 인구 증가 -> 사고 증가
```

즉 상관관계가 있다고 해서 반드시 인과관계가 있는 것은 아니다.

## 결론 도출 오류 예

리뷰가 5개인 상품의 평점이 5.0이고, 리뷰가 500개인 상품의 평점이 3.8이라고 하자. 단순 평균만 보면 리뷰 5개 상품이 더 좋아 보인다.

하지만 리뷰 수가 너무 적으면 한두 개 평가에 평균이 크게 흔들린다. 따라서 평균뿐 아니라 표본 수, 분산, 이상치 여부를 함께 확인해야 한다.

## AI와 사람의 역할 분담

AI와 사람은 다음처럼 역할을 나누는 것이 좋다.

| 역할 | AI | 사람 |
| --- | --- | --- |
| 데이터 정리 | 형식 통일, 파일 병합, 누락값 탐지 | 정리 기준 검토 |
| 분석 수행 | 패턴 탐색, 차트 생성, 가설 제안 | 업무상 의미 판단 |
| 결과 해석 | 전략 옵션과 리스크 제안 | 최종 의사결정 |
| 반복 환경 구축 | 대시보드 생성, 자동 갱신 구조 구성 | 사용 목적과 지표 정의 |

AI는 분석 속도를 높이고 시야를 넓혀주지만, 데이터의 맥락과 책임 있는 판단은 사용자가 맡아야 한다.

## 정리

생성형 AI 서비스를 활용하면 코딩 없이 자연어만으로 데이터 전처리, 분석, 시각화, 보고서 작성, 대시보드 구축을 수행할 수 있다. 사용자는 코드 문법보다 분석 목표와 해석에 집중할 수 있다.

분석 품질을 높이려면 AI에게 후속 질문을 던지고, 업무 맥락을 추가하며, 결과를 비판적으로 검토해야 한다. 특히 상관관계와 인과관계를 혼동하거나 적은 데이터로 성급한 결론을 내리는 오류를 경계해야 한다.
