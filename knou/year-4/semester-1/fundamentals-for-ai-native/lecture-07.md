# 7강. 생성형 AI 서비스의 부가 기능과 업무 활용

- 학습일: 2026-08-28
- 과목: AI네이티브가되기위한기초소양
- 주제: 웹 검색, 파일 업로드, 메모리, 에이전트형 AI, 업무 실습

## 핵심 요약

생성형 AI 서비스는 대규모 언어 모델에 사용자 화면과 여러 부가 기능을 결합한 형태다. 기본 LLM은 학습 시점 이후의 정보, 비공개 문서, 사용자의 개인 맥락을 알 수 없다는 한계가 있으므로 웹 검색, 파일 업로드, 메모리와 대화 이력 같은 기능을 통해 이를 보완한다.

최근에는 단순히 답변을 생성하는 수준을 넘어, AI가 웹브라우저나 로컬 파일을 직접 조작해 예약, 정리, 문서 생성, 발표 자료 제작 같은 실제 업무를 수행하는 에이전트형 활용 방식으로 확장되고 있다.

## 생성형 AI 서비스의 주요 활용 분야

생성형 AI 서비스는 여러 업무에서 활용할 수 있다.

| 활용 분야 | 설명 |
| --- | --- |
| 정보 분석 및 요약 | 긴 문서나 자료에서 핵심 정보 추출 |
| 언어 변환 및 교정 | 번역, 문체 개선, 맞춤법 교정 |
| 문서 작성 및 편집 | 이메일, 보고서, 기획안, 발표문 작성 |
| 코딩 | 코드 생성, 설명, 변환, 디버깅 |
| 이미지 생성 및 분석 | 이미지 제작, 시각 자료 해석 |

이 기능들은 공통적으로 사용자의 목적에 맞는 결과물을 빠르게 만들어 업무 시간을 줄이는 데 초점을 둔다.

## LLM의 한계

LLM은 학습 데이터를 기반으로 응답을 생성하므로 다음 정보에는 기본적으로 접근하기 어렵다.

| 한계 | 예 |
| --- | --- |
| 학습 완료 이후의 정보 | 최신 뉴스, 오늘의 날씨, 신규 제품 정보 |
| 비공개 데이터 | 개인 문서, 사내 매뉴얼, 계약서, 업무 보고서 |
| 개인 맥락 | 사용자의 직업, 선호하는 답변 형식, 과거 대화 이력 |

생성형 AI 서비스의 부가 기능은 이러한 정보를 추가 입력으로 제공해 답변 품질을 높인다.

## 웹 검색 기능

웹 검색 기능은 LLM의 학습 시점 이후에 발생한 최신 정보를 검색해 답변에 반영한다.

대표적인 활용 사례는 다음과 같다.

1. 최신 시장 동향을 바탕으로 기업 분석하기
2. 최근 정책이나 규제 변경 사항 검토하기
3. 실시간 환율이나 지수 데이터를 활용해 현황 파악하기
4. 최신 논문, 보고서, 기사 기반으로 리서치하기

웹 검색 결과는 출처와 함께 제시될 수 있으므로, 사용자는 답변의 근거를 직접 확인하고 신뢰성을 검토할 수 있다.

## 파일 업로드 기능

파일 업로드 기능은 LLM의 학습 데이터에 포함되지 않은 사용자의 문서를 분석하게 해준다.

예를 들어 다음과 같은 작업에 활용할 수 있다.

| 문서 유형 | 활용 예 |
| --- | --- |
| 계약서 | 핵심 조항 요약, 위험 조항 검토 |
| 재무제표 | 문서 종류, 대상 기간, 검토 의견 구조화 |
| 강의 자료 | 핵심 개념 요약, 복습 문제 생성 |
| 업무 보고서 | 성과 요약, 비교표 작성, 발표 자료 초안 생성 |

문서를 업로드한 뒤 원하는 목적과 형식을 함께 지정하면 결과를 더 정확하게 얻을 수 있다.

```text
이 문서를 세 줄로 요약해줘.
핵심 내용만 5개의 bullet point로 정리해줘.
블로그 작성용으로 간결하게 요약해줘.
```

## 메모리와 과거 대화 기억

메모리 기능은 사용자의 직업, 관심사, 반복되는 요구사항 같은 맥락 정보를 저장하고 이후 답변에 반영한다.

예를 들어 사용자가 이전 대화에서 “25명의 원생을 담당하는 유치원 교사”라고 말한 적이 있다면, 이후 “현장학습 계획해줘”라고만 입력해도 AI가 유치원 원생 25명에 맞는 계획을 제안할 수 있다.

메모리 기능의 장점은 다음과 같다.

| 장점 | 설명 |
| --- | --- |
| 반복 입력 감소 | 매번 배경 정보를 다시 설명하지 않아도 됨 |
| 답변 일관성 향상 | 사용자의 역할과 선호를 반영 |
| 개인화 | 사용자 맥락에 맞는 예시와 형식 제공 |

다만 개인 정보나 업무상 민감한 정보가 저장될 수 있으므로 설정과 저장 내용을 주기적으로 확인하는 것이 좋다.

## 부가 기능의 조합

웹 검색, 파일 업로드, 메모리는 각각 독립적으로도 유용하지만 조합하면 더 강력하다.

```text
업로드 문서 + 웹 검색 + 원하는 결과 형식
```

예를 들어 기술 보고서를 업로드하고 “블로그 작성용으로 핵심만 요약해줘”라고 요청하면, AI는 문서 내용을 기반으로 목적에 맞는 요약본을 생성한다. 여기에 웹 검색을 더하면 최신 관련 정보까지 반영한 리포트를 만들 수 있다.

## 생성형 AI 서비스 활용 방식의 변화

기존 방식에서는 AI가 답변을 생성하면 사용자가 그 결과를 복사해 다른 도구에 붙여 넣고, 이후 작업은 직접 수행해야 했다.

```text
질문 -> 답변 생성 -> 사용자가 복사 -> 다른 프로그램에서 직접 작업
```

최근에는 AI가 웹브라우저나 업무 프로그램을 직접 조작하는 방식으로 발전하고 있다.

```text
업무 지시 -> AI가 도구 조작 -> 파일 수정 또는 작업 실행
```

예를 들어 “엑셀 파일에서 region 값이 East인 행을 위로 정렬해줘”라고 요청하면 AI가 파일 구조를 파악하고 직접 정렬을 수행할 수 있다.

## 에이전트형 AI

에이전트형 AI는 사용자의 목표를 이해한 뒤 여러 단계를 스스로 계획하고 실행하는 AI 활용 방식이다.

대표적인 작업은 다음과 같다.

| 작업 | 예 |
| --- | --- |
| 웹 탐색 | 여러 사이트에서 상품, 식당, 자료 검색 |
| 양식 입력 | 예약 날짜, 인원, 신청 정보 자동 입력 |
| 파일 조작 | 문서 작성, 표 생성, 발표 자료 제작 |
| 최종 실행 대기 | 결제, 예약 확정 전 사용자 승인 요청 |

예약이나 주문처럼 실제 결과가 발생하는 작업은 사용자의 최종 확인을 받는 방식이 바람직하다.

## 브라우저 조작 예: ChatGPT Atlas

ChatGPT Atlas는 AI 기반 웹브라우저의 예로 소개된다. 사용자가 자연어로 지시하면 브라우저에서 검색, 조건 설정, 페이지 이동, 양식 입력을 수행한다.

예를 들어 다음 요청을 처리할 수 있다.

```text
4월 15일 저녁 7시경 강남 부근에서 네이버 예약이 가능한 한식 맛집을 찾아서 2명 예약까지 진행해줘.
```

이 경우 AI는 검색어를 입력하고, 지도나 예약 페이지에 접근하며, 날짜와 인원을 설정하고, 적합한 음식점을 선택한다. 최종 예약 신청처럼 중요한 실행은 사용자 승인 직전에서 멈추도록 설계할 수 있다.

## 로컬 파일 조작 예: Claude Code/CoWork

Claude의 업무 보조 기능은 로컬 폴더와 연결해 Word, Excel, PowerPoint 같은 파일을 직접 생성하거나 편집하는 예로 소개된다.

예를 들어 다음 요청을 줄 수 있다.

```text
가상의 주간 회의 내용을 바탕으로 회의록 Word 파일과 액션 아이템 Excel 파일을 만들어줘.
```

AI는 회의 안건, 결정사항, 액션 아이템, 담당자, 기한, 상태를 정리하고 실제 문서 파일과 표 파일을 생성할 수 있다. 파일 시스템 접근은 권한 요청을 통해 사용자가 허용해야 한다.

## 실습 1: 제품 기획을 위한 시장 조사

첫 번째 실습은 민감성 피부용 화장품 신제품을 기획하는 상황을 가정한다. 목표는 국내 뷰티 시장에서 피부 진정 관련 제품 트렌드를 조사하고, 판매 상위 제품들의 공통점을 분석해 신제품 방향성을 잡는 것이다.

작업 흐름은 다음과 같다.

1. 분석 목표를 입력한다.
2. AI가 작업 계획을 세운다.
3. 여러 웹사이트에서 정보를 수집한다.
4. 제품별 가격, 리뷰 수, 핵심 성분을 비교한다.
5. 공통 어필 요소와 기획 시사점을 정리한다.

프롬프트 예시는 다음과 같다.

```text
국내 뷰티 시장에서 시카 에센스 제품 중 판매량이 높은 제품들을 분석해줘.
각 제품의 가격대, 리뷰 수, 핵심 성분을 비교표로 정리하고
상위권 제품들이 공통적으로 어필하는 성분, 효능, 타겟을 기획 관점에서 정리해줘.
```

심층 리서치 기능을 사용하면 AI가 검색 계획을 세우고 여러 공개 페이지를 비교한 뒤 하나의 보고서로 정리한다.

## 시장 조사 결과 활용

리서치 결과는 단순 목록이 아니라 기획 의사결정의 근거가 되어야 한다.

예를 들어 피부 진정 제품의 상위권 제품들이 다음 요소를 함께 강조한다면, 신제품 기획에서도 이를 고려할 수 있다.

| 공통 요소 | 기획 시사점 |
| --- | --- |
| 진정 성분 | 병풀, 시카 등 핵심 성분 강조 |
| 트러블 자국 케어 | 단순 진정보다 피부 고민 해결 메시지 강화 |
| 피부 장벽 회복 | 민감성 피부 대상의 신뢰감 형성 |
| 수분 공급 | 보습 효능을 함께 제시 |
| 적정 가격대 | 경쟁 제품의 실구매가를 기준으로 가격 설계 |

AI 리서치는 자료 수집 시간을 줄여 기획자가 해석과 의사결정에 더 집중하게 해준다.

## 실습 2: 상세 페이지 카피와 이미지 생성

시장 조사 이후에는 신제품 상세 페이지에 들어갈 마케팅 문구와 이미지를 만들 수 있다.

가상의 제품 예시는 다음과 같다.

| 항목 | 내용 |
| --- | --- |
| 브랜드 | 하나랩 |
| 제품명 | 시카 히알 앰플 |
| 핵심 성분 | 병풀수 70%, 10종 히알루론산 |
| 주요 효능 | 트러블 진정, 보습 |
| 타겟 | 피부 트러블이 고민인 20~30대 |

카피 요청 예시는 다음과 같다.

```text
이 제품의 상세 페이지 상단 대표 이미지 영역에 들어갈 메인 카피와 보조 카피를 작성해줘.
```

이후 생성된 카피를 바탕으로 흰 배경, 미니멀한 더마 코스메틱 스타일, 넉넉한 여백 등 이미지 스타일을 지정해 상세 페이지 히어로 이미지를 만들 수 있다.

## 실습 3: 이미지에서 광고 영상으로 확장

이미지 생성 후에는 해당 이미지를 첫 프레임으로 삼아 짧은 광고 영상을 만들 수 있다.

영상 프롬프트는 시간 흐름에 따라 나누어 작성하는 것이 좋다.

```text
0초부터 4초까지는 모델이 제품 병을 두 손으로 잡고 부드럽게 돌려 라벨을 확인한다.
4초부터 8초까지는 고개를 살짝 기울이며 만족스러운 미소를 짓는다.
마지막에는 카메라가 살짝 멀어지며 제품이 화면 중앙에 남는다.
```

영상 생성은 이미지 생성보다 통제가 어려울 수 있다. 지시한 동작이 정확히 반영되지 않으면 다시 생성하거나, 특정 영역 수정이 가능한 영상 편집 특화 서비스를 활용할 수 있다.

## 실습 4: 보고서 요약과 발표 자료 생성

두 번째 큰 실습 주제는 여러 부서의 분기 보고서를 분석하고, 요약 문서와 발표 자료를 생성하는 것이다.

예를 들어 마케팅팀, 영업팀, CS팀의 1분기 업무 보고서를 업로드하고 다음을 요청할 수 있다.

```text
업로드한 3개의 보고서를 비교 분석해줘.
각 팀별 핵심 성과를 요약하고,
캠페인 전환율, 신규 거래처, 고객 만족도 같은 수치를 정리해줘.
공통점과 차이점은 표로 비교해줘.
```

이후 추가로 다음 요청을 이어갈 수 있다.

```text
이 비교 분석을 바탕으로 임원 보고용 10분 발표 구성안을 만들어줘.
슬라이드별로 어떤 내용을 넣을지 기획해줘.
```

에이전트형 파일 생성 기능을 사용하면 요약 분석은 Word 파일로, 발표 자료는 PowerPoint 파일로, 발표 스크립트는 별도 문서로 생성하게 할 수 있다.

## 도구 선택 기준

작업 성격에 따라 적합한 생성형 AI 서비스를 선택해야 한다.

| 작업 | 적합한 기능 |
| --- | --- |
| 최신 정보 조사 | 웹 검색, 심층 리서치 |
| 내부 문서 분석 | 파일 업로드 |
| 반복되는 개인 맥락 반영 | 메모리, 대화 이력 |
| 웹사이트 탐색과 예약 | 브라우저 조작형 에이전트 |
| 문서·표·발표 자료 생성 | 로컬 파일 조작형 에이전트 |
| 이미지와 영상 제작 | 이미지·영상 생성 모델 |

중요한 점은 AI를 하나의 만능 도구로 보기보다, 업무 단계별로 적합한 기능을 조합하는 것이다.

## 정리

생성형 AI 서비스는 웹 검색, 파일 업로드, 메모리 기능을 통해 LLM의 한계를 보완한다. 또한 에이전트형 기능을 통해 브라우저, 문서, 표, 발표 자료까지 직접 조작하는 방향으로 발전하고 있다.

업무에서는 분석 목표와 결과 형식을 명확히 제시하고, 필요한 경우 파일과 최신 정보를 함께 제공하는 것이 중요하다. 시장 조사, 상세 페이지 제작, 광고 영상 생성, 보고서 요약과 발표 자료 제작처럼 여러 단계가 있는 업무일수록 AI의 계획 수립과 자동화 기능을 효과적으로 활용할 수 있다.
