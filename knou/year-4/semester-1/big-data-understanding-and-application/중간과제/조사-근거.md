# 빅데이터의 이해와 활용: 1번 문항 조사 근거

조사일: 2026-10-28. 정부·공공기관의 자료와 개발자 본인의 기고를 우선 확인했다. 이 파일은 답안 작성용 근거이며 제출 본문은 아니다.

## 1. 2009년 서울버스: 초기 웹사이트 활용과 이후 개방을 구분

- **핵심 1차 자료:** 유주완 서울버스모바일 대표, 「혁신의 첫 걸음, 공공정보 개방」, 정부 정책주간지, 2013-09-09. [개발자 본인의 기고](https://gonggam.korea.kr/newsContentView.es?b_list=9&code_cd=0102000000&content=NC002&mid=a12602000000&nPage=778&news_id=EBC6D401386A4203E0540021F662AC5F&section_id=NCCD_POLICY)
- 개발자는 지역별 버스정보 사이트를 앱과 연결하는 방식으로 서비스를 만들었고, 2009년 12월 초 출시했다고 설명한다. 이용 증가로 한 지역에서 정보 이용이 차단된 경험도 기록한다.
- 이 자료로 **초기 웹사이트 기반 정보 활용**, **접근 차단 가능성**, **공공정보 개방 필요성**을 설명할 수 있다. 다만 모든 지역에 동일한 HTML 파서를 사용했다거나 개발자가 수작업으로 밤낮 데이터를 복사했다는 구현 세부사항까지 입증하지는 않는다.
- 따라서 2009년 사례를 처음부터 정식 오픈 API만 사용했다고 교정하면 안 된다. 초기 비정형 웹 정보 활용과 이후 공식 개방을 구분하는 설명이 적절하다.
- 보조 자료: 서울시 「서울 열린 데이터 광장 백서」 인쇄쪽 16~17은 초기 지역별 버스정보 사이트 연결, 일부 정보 차단, 이후 Open API 제공을 설명한다. [서울시 백서](https://seoulsolution.kr/sites/default/files/policy/%EC%84%9C%EC%9A%B8%EC%97%B4%EB%A6%B0%EB%8D%B0%EC%9D%B4%ED%84%B0%EA%B4%91%EC%9E%A5%20%EB%B0%B1%EC%84%9C.pdf). 검색 결과의 본문으로 확인했으나 직접 열기는 502 오류였다. 답안에서는 위 개발자 기고를 우선 인용한다.

## 2. 2020년 공적 마스크: 오픈 API를 통한 민관협력

- **1차 자료:** 과학기술정보통신부, 「“마스크 있는 곳, 앱으로 확인하세요”…마스크 판매정보 공개」, 2020-03-10. [정부 발표](https://www.korea.kr/news/policyNewsView.do?newsId=148870119)
- 데이터 흐름은 **건강보험심사평가원 판매처·판매현황 → 한국정보화진흥원의 주소 결합 등 재가공 → 네이버 클라우드의 오픈 API → 민간 웹·앱 개발**이다.
- 이 사례를 서울시 버스정보 웹사이트 스크래핑이라고 설명하는 것은 데이터의 대상, 제공기관, 전달방식을 모두 혼동한 것이다.
- 발표는 당일 19시 데이터 공개 및 이후 안정화 계획을 설명한다. API가 제공된다는 사실이 데이터 지연이나 서비스 오류가 전혀 없음을 뜻하지는 않는다.

## 3. 공공데이터법 연도 확인

- **1차 자료:** 국가법령정보센터의 「공공데이터의 제공 및 이용 활성화에 관한 법률」 제정문. [2013년 제정 법률](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=142444&viewCls=lsRvsDocInfoR)
- 법률 제11956호, **2013-07-30 제정·공포**, **2013-10-31 시행**이다.
- 연혁 교차 확인: [한국법제연구원 영문법령 이북의 연혁](https://elaw.klri.re.kr/kor_service/ebook.do?hseq=70389).
- 그러므로 2009년은 이 법 시행 전이지만 2020년은 시행 후다. 두 사례가 모두 ‘공공데이터 개방 법률이 없던 시절’이라는 지문은 잘못되었다.
- 이 법이 제정되기 전에는 어떠한 공공정보 제공도 불가능했다는 뜻은 아니다. 제정법 부칙 제2조는 시행 전 다른 법령이나 공공기관 협의로 제공받던 데이터의 경과조치를 두고 있다.

## 4. 공공 API의 실시간 제공 반례

- [서울특별시 버스위치정보조회 서비스, 공공데이터포털](https://www.data.go.kr/data/15000332/openapi.do)는 서울 시내버스의 실시간 위치 정보를 제공한다고 명시한다.
- ‘오픈 API는 실시간 데이터를 제공할 수 없다’는 지문에 대한 직접적인 반례다. 다만 실시간성은 데이터 생산·갱신 주기와 지연에 좌우되므로 모든 API가 무지연 실시간이라고 반대로 일반화하지 않는다.
- 현재 API 존재는 2009년 서울버스 앱이 당시에도 같은 API를 사용했다는 증거가 아니다. 역사적 사례와 현재의 기술적 가능성을 분리하여 인용한다.

## 5. 답안에 반영할 교정 원칙

1. 서울버스의 초기 웹사이트 활용을 전부 오픈 API로 바꾸지 않는다.
2. 마스크 앱은 공공기관 데이터 개방과 오픈 API를 이용한 민관협력 사례로 교정한다.
3. 스크래핑의 접근 차단·사이트 구조 의존과 API의 명세·이용조건 의존을 구분한다.
4. 법률 시행 전후와 기술적 수집방식은 별개의 문제다. 법률의 유무만으로 특정 앱의 구현 방식을 결정하지 않는다.
5. 지문의 ‘전혀 없다’, ‘불가능하다’, ‘전부’와 같은 단정은 개별 근거로 검토하며 반대 방향의 무조건적 단정으로 바꾸지 않는다.
