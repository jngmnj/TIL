# 3강. 유한 오토마타

- 학습일: 2026-08-25
- 과목: 컴파일러구성
- 주제: 유한 오토마타, 정규 표현과 FA, NFA와 DFA

## 핵심 요약

유한 오토마타는 문자열이 특정 언어에 속하는지 판단하는 수학적 모델이다. 컴파일러의 어휘 분석 단계에서는 정규문법이나 정규 표현으로 정의된 어휘를 유한 오토마타로 표현하고, 이를 구현해 어휘분석기로 사용한다.

유한 오토마타는 크게 NFA와 DFA로 나뉜다. NFA는 구현이 비효율적일 수 있으므로, 실제 구현에서는 DFA로 변환해 사용하는 것이 중요하다.

## 유한 오토마타란

유한 오토마타는 입력 문자열을 읽고, 그 문자열이 문법에 맞으면 `yes`, 맞지 않으면 `no`를 반환하는 모델이다.

어휘 분석 관점에서는 다음 역할을 한다.

```text
입력 문자열 -> 유한 오토마타 -> 올바른 어휘인지 판정
```

예를 들어 식별자 규칙을 유한 오토마타로 표현하면, `abc`나 `b7a8`은 올바른 식별자로 판정되고 `b=7`은 중간에 허용되지 않는 기호가 나오므로 식별자가 아니라고 판정된다.

## 식별자 인식 예

식별자 규칙을 다음처럼 둔다.

1. 첫 글자는 영문자다.
2. 두 번째 글자부터는 영문자나 숫자가 올 수 있다.
3. 길이 제한은 생략한다.

상태 전이로 표현하면 다음과 같다.

| 현재 상태 | 입력 | 다음 상태 |
| --- | --- | --- |
| `q0` | 영문자 | `q1` |
| `q0` | 숫자 | 전이 없음 |
| `q1` | 영문자 또는 숫자 | `q1` |

`q0`는 시작 상태이고, `q1`은 종료 상태다. 입력을 모두 읽은 뒤 종료 상태에 있으면 올바른 식별자로 인정한다.

## 유한 오토마타의 구성 요소

유한 오토마타 `M`은 다음 다섯 가지 요소로 정의한다.

```text
M = (Q, Σ, δ, q0, F)
```

| 구성 요소 | 의미 |
| --- | --- |
| `Q` | 상태들의 유한 집합 |
| `Σ` | 입력 기호들의 집합 |
| `δ` | 전이 함수 |
| `q0` | 시작 상태 |
| `F` | 종료 상태들의 집합 |

전이 함수 `δ`는 현재 상태와 입력 기호가 주어졌을 때 다음 상태를 결정한다.

## 상태 전이도와 전이 함수

유한 오토마타는 그림으로는 상태 전이도로 표현하고, 형식적으로는 전이 함수나 전이표로 표현한다.

| 표현 | 설명 |
| --- | --- |
| 상태 | 원으로 표현 |
| 시작 상태 | 시작 화살표가 들어오는 상태 |
| 종료 상태 | 이중 원으로 표현 |
| 전이 | 상태 사이의 화살표 |
| 입력 기호 | 전이 화살표 위에 표시 |

상태 전이도는 사람이 이해하기 쉽고, 전이표는 프로그램으로 구현하기 쉽다.

## 정규 표현과 유한 오토마타

어휘는 정규문법으로 표현할 수 있고, 정규문법은 정규 표현으로 간단히 표현할 수 있다. 정규 표현은 다시 유한 오토마타로 바꿀 수 있다.

```text
정규문법 -> 정규 표현 -> 유한 오토마타 -> 어휘분석기 구현
```

즉 모든 정규 표현은 유한 오토마타로 표현 가능하다.

## 기본 정규 표현의 FA 표현

| 정규 표현 | FA 의미 |
| --- | --- |
| `a` | 입력 `a`를 읽으면 시작 상태에서 종료 상태로 이동 |
| `a + b` | `a` 또는 `b`를 읽으면 종료 상태로 이동 |
| `a+` | `a`를 한 번 이상 반복 |
| `a*` | `a`를 0번 이상 반복, `ε` 포함 |
| `(a + b)*` | `a` 또는 `b`를 0번 이상 반복 |

`a*`는 공문자열 `ε`을 포함하므로 아무 입력 없이도 종료 상태가 될 수 있다.

## 정규 표현 예

다음 정규 표현을 생각해보자.

```text
(a + b)*abb
```

이 표현은 `a` 또는 `b`가 여러 번 반복된 뒤, 마지막이 반드시 `abb`로 끝나는 문자열을 의미한다.

`*`가 공문자열을 허용하므로 `abb`도 이 언어에 포함된다.

## NFA와 DFA

유한 오토마타는 NFA와 DFA로 구분된다.

| 구분 | NFA | DFA |
| --- | --- | --- |
| 이름 | Non-deterministic Finite Automata | Deterministic Finite Automata |
| 전이 | 하나의 입력에 대해 여러 상태로 갈 수 있음 | 하나의 입력에 대해 하나의 상태로만 감 |
| ε 전이 | 가능 | 없음 |
| 구현 | 상대적으로 비효율적 | 구현이 단순하고 효율적 |
| 관계 | DFA로 변환 가능 | NFA의 특수한 형태 |

NFA는 표현하기 쉽지만 실행 경로가 여러 개일 수 있다. 따라서 실제 어휘분석기 구현에서는 NFA를 DFA로 바꾸는 과정이 필요하다.

## NFA가 되는 경우

NFA는 다음 두 가지 경우를 포함한다.

1. `ε` 전이가 있다.
2. 하나의 상태와 하나의 입력 기호에 대해 두 개 이상의 다음 상태가 있다.

예를 들어 `q0`에서 입력 `0`을 읽었을 때 `q0`과 `q1` 두 상태로 모두 갈 수 있다면 NFA다.

## ε-closure

`ε-closure`는 어떤 상태에서 `ε` 전이만 따라가서 도달할 수 있는 모든 상태의 집합이다. 자기 자신도 포함한다.

예를 들어 상태 `0`에서 `ε` 전이를 통해 `1`, `2`, `4`에 갈 수 있다면 다음처럼 표현한다.

```text
ε-closure(0) = { 0, 1, 2, 4 }
```

여러 상태의 `ε-closure`는 각 상태의 `ε-closure`를 합집합으로 구한다.

```text
ε-closure({3, 9}) = ε-closure(3) ∪ ε-closure(9)
```

## ε 전이가 있는 NFA를 DFA로 바꾸기

ε 전이가 있는 NFA는 다음 절차로 DFA로 변환한다.

1. 시작 상태의 `ε-closure`를 구해 DFA의 시작 상태로 둔다.
2. 해당 상태 집합에서 각 입력 기호로 갈 수 있는 상태들을 찾는다.
3. 그 결과에 다시 `ε-closure`를 적용한다.
4. 새로 나온 상태 집합을 DFA의 새로운 상태로 둔다.
5. 더 이상 새로운 상태 집합이 나오지 않을 때까지 반복한다.
6. 원래 NFA의 종료 상태를 포함하는 상태 집합은 DFA의 종료 상태가 된다.

이 과정을 거치면 ε 전이가 제거되고, 각 입력에 대해 하나의 다음 상태만 갖는 DFA를 얻을 수 있다.

## 여러 상태 전이가 있는 NFA를 DFA로 바꾸기

하나의 입력에 대해 여러 상태로 갈 수 있는 경우에는 상태들의 집합 자체를 하나의 새로운 상태로 본다.

예를 들어 다음 전이가 있다고 하자.

```text
δ(q0, 0) = { q0, q1 }
```

그러면 `{q0, q1}`을 DFA의 하나의 상태처럼 취급한다. 이후 `{q0, q1}`에서 각 입력 기호를 읽었을 때 갈 수 있는 상태들의 합집합을 다시 구해 전이표를 완성한다.

이 방법을 부분집합 구성법이라고 볼 수 있다.

## 도달 불가능 상태 제거

DFA로 변환한 뒤에는 시작 상태에서 도달할 수 없는 상태가 생길 수 있다. 이런 상태는 실제 문자열 인식 과정에서 사용되지 않으므로 제거한다.

도달 불가능 상태를 제거하면 상태 전이도가 더 단순해지고 구현도 쉬워진다.

## 정리

유한 오토마타는 정규 표현으로 정의된 어휘를 인식하는 수학적 모델이다. 정규 표현은 유한 오토마타로 표현할 수 있고, 유한 오토마타는 어휘분석기로 구현할 수 있다.

NFA는 표현이 유연하지만 구현이 비효율적일 수 있으므로, 실제 구현에서는 DFA로 변환한다. 이를 위해 ε-closure와 상태 집합을 하나의 상태로 보는 변환 방법을 사용한다.
