# 6강. 딥러닝의 원리

- 학습일: 2026-09-24
- 과목: AI 리터러시
- 주제: 인공신경망, 계층 구조, 표현학습, 딥러닝의 강점과 한계

## 핵심 요약

**딥러닝은 여러 처리 층을 통해 데이터의 표현을 학습하는 머신러닝 방법이다.** 이미지·음성·언어처럼 복잡한 자료에서 유용한 특징을 배울 수 있지만, 좋은 성능이 결과의 정확성이나 설명 가능성을 항상 보장하지는 않는다.

| 핵심 개념 | 의미 | 주의할 점 |
| --- | --- | --- |
| 깊이 | 여러 처리 층이 연결된 구조 | 층이 많다고 무조건 성능이 좋아지는 것은 아님 |
| 계층적 처리 | 앞선 층의 표현을 다음 층에서 변환·조합 | 모든 층에 사람이 이해할 수 있는 역할이 정해져 있지는 않음 |
| 표현학습 | 과제에 유용한 내부 표현을 데이터에서 학습 | 현실 전체를 그대로 복제하는 과정은 아님 |
| 일반화 | 학습에 없던 사례에서도 잘 작동하는 능력 | 실제 사용 환경에서 별도로 검증해야 함 |
| 설명 가능성 | 결과가 나온 근거를 사람이 검토할 수 있는 정도 | 높은 예측 성능과 구별해야 함 |

강의는 수학적 계산보다 작동 원리, 활용 가능성, 결과를 검토하는 기준에 초점을 둔다.

## 1. 인공신경망에서 딥러닝으로

### 인공신경망과 딥러닝의 관계

인공신경망은 연결된 계산 단위들이 입력을 변환하여 출력을 만드는 모델이다. 딥러닝에서는 여러 층으로 이루어진 신경망을 통해 다양한 수준의 표현을 학습한다.

```text
입력 데이터
  → 여러 층에서 표현을 변환·조합
  → 학습된 표현을 이용한 분류·예측 등의 출력
```

**딥러닝은 인공신경망과 별개인 기술이 아니다.** ‘신경망인가, 딥러닝인가’를 특정 함수의 종류만으로 구분하지 않는다. 또한 모든 분야에 공통으로 적용되는 단일한 층수 기준이 있는 것도 아니다.

> 보충: 여러 처리 층과 추상화 수준의 표현학습이라는 설명은 LeCun·Bengio·Hinton의 [Deep learning](https://doi.org/10.1038/nature14539)에 근거한다. 원문의 ‘함수의 차이로 구분한다’는 설명은 일반적인 구분 기준으로 사용하지 않았다.

### 층은 무엇을 하는가?

각 층은 이전 단계의 값을 받아 새로운 표현으로 변환한다. 강의에서는 이를 **단순한 단서를 조합해 더 복잡한 특징을 만드는 과정**으로 설명한다.

| 단계 | 이미지 인식의 설명용 예시 |
| --- | --- |
| 입력 | 픽셀의 밝기·색상 값 |
| 낮은 층 | 선의 방향, 경계와 같은 국소적인 단서 |
| 중간 층 | 곡선, 무늬, 부분 형태 |
| 높은 층 | 여러 부분의 조합과 분류에 유용한 특징 |
| 출력 | 숫자나 사물의 종류에 대한 예측 |

이 표는 계층적 처리를 이해하기 위한 도식이다. 실제 모델의 모든 층이 반드시 ‘선 → 귀 → 고양이’ 순서로 나뉘거나 특정 사물 이름에 대응하는 것은 아니다.

### 학습과 추론 구별하기

강의의 숫자·고양이 분류 사례는 정답 라벨을 사용하는 학습을 중심으로 설명한다.

```text
학습: 입력과 목표 준비 → 예측 → 오차 계산 → 매개변수 조정 → 반복
추론: 새 입력 → 학습된 매개변수로 계산 → 결과 출력
```

- **연결 강도(가중치)**: 입력의 영향과 표현의 변환에 관여하는 학습 가능한 값이다.
- **학습**: 목표와 예측의 차이를 줄이도록 가중치 등을 조정하는 과정이다.
- **추론**: 학습된 모델을 사용해 새로운 입력의 결과를 계산하는 과정이다.

처음부터 학습할 때는 가중치를 초기화하고 조정해 나간다. 이미 학습된 모델에서 출발해 추가 학습하는 경우도 있다. 추론할 때마다 가중치를 다시 학습하는 것은 아니다.

데이터가 많다는 이유만으로 정확성이 보장되지는 않는다. 자료의 품질과 대표성, 학습 목표, 모델, 평가 조건을 함께 봐야 한다. 또한 딥러닝 전체가 사람이 붙인 정답 라벨을 필요로 하는 것은 아니며, 강의의 분류 예시는 여러 학습 방식 중 하나다.

## 2. 계층 구조와 표현학습

### 손글씨 숫자 인식

손으로 쓴 숫자 `8`을 입력하면 컴퓨터는 이를 이미지의 수치 배열로 처리한다.

1. 픽셀에서 선과 경계에 관한 단서를 처리한다.
2. 단서들을 조합해 곡선이나 고리 같은 형태를 표현한다.
3. 학습된 표현을 바탕으로 각 숫자에 대한 점수 등을 계산한다.
4. 결과를 이용해 `8`이라는 예측을 출력한다.

‘두 개의 고리를 보고 8이라고 판단한다’는 설명은 이해를 돕는 비유다. 모델 내부에 사람이 쓴 규칙이 그대로 들어 있다고 가정해서는 안 된다.

또한 일반적인 신경망 분류가 **저장된 과거 이미지들을 매번 하나씩 대조하는 방식**인 것은 아니다. 학습을 통해 조정된 매개변수가 새 입력의 계산에 사용된다.

### 고양이 사진 인식

고양이 사진에는 색, 경계, 귀·눈·수염·털의 형태 등 다양한 단서가 있다. 모델은 이런 자료에서 분류에 유용한 표현을 학습할 수 있다.

| 확인할 점 | 의미 |
| --- | --- |
| 여러 단서의 조합 | 특정 특징 하나만으로 분류한다고 가정하지 않음 |
| 배경의 영향 | 의도한 사물 외의 단서를 사용할 가능성도 있음 |
| 촬영 조건 | 조명·각도·배경이 바뀌었을 때도 성능을 확인 |
| 출력 해석 | 높은 점수나 확률 형태의 출력이 정답을 보장하지 않음 |

사진을 잘 분류한다는 사실만으로 사람이 가진 경험·상식과 같은 방식으로 사물을 이해한다고 결론 내릴 수는 없다.

### 사람이 정한 특징과 학습한 특징

| 구분 | 사람이 특징을 설계하는 접근 | 딥러닝의 표현학습 |
| --- | --- | --- |
| 특징을 준비하는 방식 | 전문가가 유용할 것으로 예상한 변수를 구성 | 학습 과정에서 유용한 내부 표현을 형성 |
| 예시 | 윤곽·색상 등의 측정값을 입력으로 준비 | 이미지에서 여러 층의 표현을 학습 |
| 장점 | 특징의 의미를 파악하기 비교적 쉬움 | 복잡한 자료의 특징을 일일이 열거할 부담을 줄임 |
| 한계 | 사람이 설계한 특징의 범위에 제약 | 학습된 표현의 의미를 설명하기 어려울 수 있음 |

두 접근이 완전히 배타적인 것은 아니다. 딥러닝에도 데이터 선택·전처리·모델 설계·학습 목표에 관한 사람의 결정이 들어간다. 사람이 특징을 설계한 모델도 전체 판단 과정을 항상 쉽게 설명할 수 있는 것은 아니다.

### 표현학습이란?

**표현학습(representation learning)**은 과제를 수행하는 데 유용한 데이터의 표현을 학습하는 것이다. 단순히 파일 형식을 바꾸거나 자료를 정리하는 것보다 넓은 개념이다.

강의에서는 이를 지도에 비유한다. 지도는 도시의 모든 것을 복제하지 않고 길·거리·위치 등 목적에 필요한 관계를 나타낸다. 모델의 내부 표현도 원자료의 모든 정보를 그대로 유지하기보다 과제에 필요한 관계를 담도록 학습될 수 있다.

따라서 내부 표현을 현실 자체와 동일시하면 안 된다. 다만 **현실의 속성이나 관계를 전혀 반영하지 않는다는 뜻도 아니다.** 무엇을 담고 무엇을 놓치는지는 데이터와 학습 목표에 영향을 받는다.

### 언어의 관계와 문맥

언어 모델은 단어가 함께 쓰이는 양상과 문맥 속 관계를 학습한다.

| 표현 | 함께 살펴볼 문맥의 예 |
| --- | --- |
| 비 | 우산, 구름, 장마, 옷이 젖음 |
| 학교 | 수업, 과제, 교실, 학생 |
| 은행 | 계좌·예금이 등장하는 금융 문맥 |
| 은행 | 나무·잎·열매가 등장하는 자연 문맥 |

같은 표기의 단어도 문맥에 따라 다른 의미로 쓰인다. 다만 함께 등장한 단어가 모든 모델의 내부 표현에서 반드시 가까워진다고 단정할 수는 없다. 구체적인 표현 방식은 모델과 학습 방식에 따라 다르다.

## 3. 딥러닝의 강점과 활용

### 이미지·음성·언어 처리

| 자료 | 처리의 단서 | 활용 예 | 점검할 조건 |
| --- | --- | --- | --- |
| 이미지 | 픽셀, 경계, 모양, 부분 간 관계 | 사물·숫자 분류 | 조명, 촬영 각도, 배경 |
| 음성 | 시간에 따른 소리의 변화 | 음성을 텍스트로 변환 | 소음, 발음, 녹음 환경 |
| 언어 | 표현의 순서와 문맥 속 관계 | 번역, 요약, 질의응답 | 생략된 맥락, 모호한 표현, 사실성 |

음성은 시간에 따른 파형이나 시간·주파수 정보를 담은 표현 등으로 처리할 수 있다. 파형의 높낮이를 곧바로 소리의 음높이나 주파수와 같은 것으로 보지는 않는다.

딥러닝은 사람이 규칙으로 일일이 적기 어려운 복잡한 관계를 학습하는 데 유용하다. 그러나 이미지를 잘 분류하거나 말을 자연스럽게 변환한다는 것만으로 결과의 의미와 원인이 검증되는 것은 아니다.

### 패턴과 이상 징후 찾기

많은 자료에서 반복되는 관계나 평소와 다른 패턴을 찾는 데 활용할 수 있다. 이때 이상 징후를 찾았다는 것은 **추가로 살펴볼 후보를 제시했다**는 의미이며, 곧바로 원인을 밝혔다는 뜻은 아니다.

강의의 의료 영상 사례도 이러한 활용 방향을 설명한다. 영상에서 관심 영역이나 이상 가능성을 제시하고, 의료진이 다른 정보와 함께 검토하는 상황을 예로 든다. 이 예시는 특정 제품의 허가 범위나 임상 성능을 주장하는 자료가 아니다.

## 4. 한계와 책임 있는 활용

### 블랙박스와 설명 가능성

딥러닝은 많은 층과 매개변수를 통해 계산하므로 특정 출력이 나온 이유를 사람이 이해할 수 있는 설명으로 정리하기 어려울 수 있다.

블랙박스라는 말은 계산 구조를 전혀 볼 수 없다는 뜻이 아니다. **계산을 추적할 수 있는 것과 결과의 이유를 사람이 이해하는 것은 다르다**는 점이 핵심이다.

의료·금융·채용·교육처럼 결정의 영향이 큰 분야에서는 설명이 오류 수정, 이의 제기, 책임 있는 검토의 출발점이 된다. 설명이 그럴듯하다는 것만으로 그 설명이 정확하거나 결과가 공정하다고 보장되지는 않는다.

### 학습 환경과 실제 환경의 차이

| 학습에서 익숙했던 조건 | 실제 사용에서 달라질 수 있는 조건 |
| --- | --- |
| 밝고 선명한 사진 | 어두운 조명, 흐림, 다른 촬영 각도 |
| 조용한 환경의 음성 | 주변 소음, 다른 발음과 말하기 속도 |
| 자주 등장한 표현 | 낯선 표현, 새로운 주제와 맥락 |
| 특정 집단의 자료 | 다른 특성을 가진 사용자 집단 |

사람에게 사소한 변화가 모델에는 중요한 단서의 변화일 수 있다. 반대로 모든 작은 변화가 반드시 큰 오류를 일으키는 것도 아니다. 실제 조건에서 성능이 유지되는지 평가해야 한다.

학습 데이터와 비슷한 환경에서도 오류는 발생할 수 있다. ‘익숙한 자료이므로 정답’이라고 가정하지 않는다.

### 사람과 시스템의 역할

강의는 중요한 결정에서 AI 출력을 검토 가능한 후보나 신호로 활용할 것을 강조한다. 이를 모든 딥러닝 서비스가 초안만 만들거나 자동 처리를 할 수 없다는 뜻으로 확대하지 않는다.

| 단계 | 확인할 일 |
| --- | --- |
| 목적 설정 | 무엇을 돕고 어떤 결정에 사용할 것인지 정함 |
| 데이터 준비 | 목적 적합성, 품질, 대표성을 살핌 |
| 성능 검증 | 실제 환경과 중요한 사용자 집단에서 평가 |
| 결과 활용 | 오류가 미치는 영향을 고려해 검토 수준 결정 |
| 운영 | 환경 변화와 오류를 살피고 수정 절차 마련 |
| 책임과 안내 | 담당자의 역할, 이의 제기 경로, 사용 사실과 한계를 명확히 함 |

사용자가 학습 데이터의 구체적인 구성을 알 수 없는 경우에도 실제 사용 목적에 적합한지는 따로 확인해야 한다. 과제에서의 AI 사용과 표시는 해당 과목의 지침을 확인한다.

### 과대평가와 과소평가 피하기

- **과대평가**: 높은 성능만 보고 모든 상황에서 정확하거나 사람의 판단을 전부 대신한다고 가정한다.
- **과소평가**: 일부 오류만 보고 복잡한 자료를 처리하는 활용 가치까지 부정한다.
- **균형 있는 평가**: 목적에 맞는 성능, 실패 조건, 검토 비용, 오류의 영향을 함께 본다.
