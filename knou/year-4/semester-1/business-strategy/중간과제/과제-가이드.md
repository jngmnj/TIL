# 경영전략론 중간과제 가이드

## 자료와 작업 범위

- 기준 자료: [경영전략론 중간과제명 PDF](../../강의자료/경영전략론중간과제명.pdf), 1쪽 전체.
- 원문 학기: **2026학년도 2학기**. 개설학과는 경영·컴퓨터, 개설학년은 4학년, 과제유형은 공통형이다.
- 저장소는 현재 `year-4/semester-1` 구조이므로 그 위치를 유지했다. 폴더명과 PDF의 학기 표기가 다르므로 수강 학기·제출 공지를 확인한다.
- 이번 작업은 경영전략론 한 과목의 과제 요구사항 분석과 작성 가이드까지다. 제출용 답안이나 기업별 분석 결과는 아직 작성하지 않았다.
- 아래에서 **원문 요구사항**과 **작성 제안**을 구분한다. 작성 제안은 추가 제출 조건이 아니다.

## 1. 원문 요구사항

### 과제 내용

글로벌 자동차 제조 산업에서 경쟁하는 기업 3개를 선정하고 VRIO 분석을 수행한다. 한국 기업도 포함할 수 있다.

| 항목 | 원문 조건 | 준비할 결과물 |
| --- | --- | --- |
| 분석 대상 | 글로벌 자동차 제조 산업의 경쟁기업 3개 | 기업 선정 이유와 비교 범위 |
| 분석 방법 | VRIO 분석표 사용 | 기업별 표 또는 기업 구분이 명확한 통합 표 |
| 강점 수 | 기업마다 적어도 5개 | 총 15개 이상의 강점에 대한 VRIO 분석 |
| 모방불가능성 설명 | 교재의 모방불가능성 요소를 이용하여 기업당 강점 2개 이상 설명 | 총 6개 이상의 강점에 대한 구체적 설명 |

기업당 2개 이상의 심층 설명 대상은 해당 기업의 VRIO 표에 적은 강점 중에서 고르면 연결이 명확하다. 이는 작업 방식 제안이며, 별도의 강점 2개를 추가하라는 뜻은 아니다.

### 작성 및 제출 형식

| 항목 | PDF 기재 내용 |
| --- | --- |
| 작성 프로그램 | 아래한글 또는 MS Word |
| 글자 크기 | 11pt |
| 줄간격 | 160% |
| 분량 | A4 기준 4매 내외 |
| 구성 | 논술형, 서론-본론-결론 |
| 포함 사항 | 목차, 참고문헌 등 포함 사항을 제시하는 문구가 있음. 안전하게 목차와 참고문헌을 포함해 준비 |
| 생성형 AI | 표에서 **출처표기 후 제한적 사용** 항목에 `0` 표시가 있음. 강의계획서 참고 문구도 있으므로 허용 범위와 표기 방법을 확인 |
| 표절 | 표절 판정 시 감점 또는 0점 처리 가능 |
| 원문 참고문헌 | 신형덕, 『잘되는 기업은 무엇이 다를까』, e-book, 시그마프레스, 2016 |

### 별도 확인이 필요한 사항

PDF에 다음 내용은 명확히 적혀 있지 않다. 임의로 정하지 말고 과목 공지·강의계획서에서 확인한다.

- 제출 마감일과 제출 경로.
- 최종 허용 확장자, 파일명 규칙, 표지 양식, 여백 규정.
- 표지·목차·참고문헌이 A4 4매 내외에 포함되는지 여부.
- Word에서 줄간격 160%를 적용하는 구체적인 설정 방법.
- 생성형 AI의 제한적 사용 범위 및 사용 내역·출처 표기 방식.

이 MD 파일은 작업용 가이드다. 최종 제출 문서는 PDF가 지정한 아래한글 또는 Word 작성 조건을 따라 별도로 준비한다.

## 2. 작성 순서 제안

### 1단계: 이론과 분석 기준 정리

먼저 [4강: 기업 자원 중심의 경쟁력 분석 Ⅰ](../lecture-04.md)에서 VRIO를 복습하고, [5강: 기업 자원 중심의 경쟁력 분석 Ⅱ](../lecture-05.md)에서 모방장벽과 조직적 활용을 확인한다. 이 노트는 보조자료이며, 과제에 사용할 **교재의 용어와 해당 쪽수는 교재에서 직접 대조**한다.

| 구분 | 분석 질문 | 작성할 근거 |
| --- | --- | --- |
| V: 가치 | 이 자원·역량이 기회 활용이나 위협 대응에 기여하는가? | 비용, 품질, 고객 편익 등과의 연결 |
| R: 희소성 | 관련 경쟁기업도 비슷한 수준으로 보유하는가? | 비교 기업과의 차이 |
| I: 모방의 어려움 | 경쟁자가 재현하거나 대체하기 어려운가? | 축적 과정, 관계, 모방 비용·시간 등의 근거 |
| O: 조직적 활용 | 기업이 해당 자원으로 성과를 내도록 조직되어 있는가? | 운영 체계, 협업, 제도, 보완 자원 |

표에서 I의 `예`는 **모방하기 어렵다**는 의미로 통일한다. 기업 전체에 한 번만 점수를 붙이지 않고 각 강점에 V·R·I·O를 각각 적용한다. 근거가 부족하면 조사 단계에서 `확인 필요`로 남긴다.

### 2단계: 경쟁기업 3개 선정

- 동일한 자동차 시장에서 비교할 수 있는 제조기업 3개를 고른다.
- 기업 전체, 계열사, 브랜드를 혼용하지 않도록 분석 단위를 명시한다.
- 분석 시점, 지역, 차종·시장 범위를 정하고 세 기업에 일관되게 적용한다.
- 기업별 공식 보고서와 비교 근거를 확보할 수 있는지 확인한 뒤 대상을 확정한다.

| 구분 | 선정 기업 | 분석 범위 | 다른 두 기업과 경쟁하는 이유 |
| --- | --- | --- | --- |
| A | 미정 | 미정 | 조사 후 작성 |
| B | 미정 | 미정 | 조사 후 작성 |
| C | 미정 | 미정 | 조사 후 작성 |

### 3단계: 기업별 강점 5개 이상과 근거 수집

생산 운영, 연구개발, 브랜드, 유통·서비스, 공급망 등의 영역에서 후보를 찾되, 단순한 영역명을 강점으로 쓰지 않는다. **어떤 구체적인 자원·역량이 어떤 효과를 만드는지** 설명할 수 있어야 한다.

연차보고서·사업보고서·공식 기술자료 등을 우선 확인하고, 희소성은 경쟁사 자료와 비교한다. 기업의 홍보 문구만으로 지속적 경쟁우위를 확정하지 않는다.

자료를 찾을 때 다음 항목을 함께 기록하면 본문과 참고문헌 작성이 쉽다.

| 기업·강점 | 확인한 사실 | 자료명·발행기관·발행일 | 페이지 또는 URL | VRIO 판단에 쓰는 이유 |
| --- | --- | --- | --- | --- |
| 작성 예정 | 확인된 사실만 기입 | 작성 예정 | 작성 예정 | 사실과 본인의 해석을 구분 |

### 4단계: VRIO 분석표 작성

아래 표를 **기업별로 한 번씩, 총 3개** 작성한다. 강점이 5개를 넘으면 행을 추가한다. 모든 항목을 무조건 `예`로 채우지 않고 근거에 맞춰 판단한다.

**기업명: [작성] / 분석 범위·기준 시점: [작성]**

| 번호 | 구체적인 강점(자원·역량) | V | R | I | O | 판단 근거·출처 | 경쟁적 의미 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 작성 예정 |  |  |  |  |  |  |
| 2 | 작성 예정 |  |  |  |  |  |  |
| 3 | 작성 예정 |  |  |  |  |  |  |
| 4 | 작성 예정 |  |  |  |  |  |  |
| 5 | 작성 예정 |  |  |  |  |  |  |

표는 요약이고 본문은 논증이다. 표에 판정만 나열하지 말고, 핵심 판단의 이유를 문장으로 설명한다. V·R·I가 충족되더라도 O의 근거가 없으면 실제로 우위를 활용하는지 추가 확인한다.

### 5단계: 기업마다 모방불가능성 2개 이상 설명

각 기업의 표에서 근거가 충분한 강점을 최소 2개 고르고, 교재의 모방불가능성 요소와 연결한다. **세 기업을 합쳐 2개가 아니라 기업마다 2개 이상**이다.

기존 5강 노트의 역사적 조건·경로의존성, 사회적 복잡성, 인과적 모호성 등을 교재와 대조해 사용할 수 있다. 특허·영업비밀 등을 다룰 때도 교재의 분류와 실제 보호 범위를 확인한다.

각 강점의 설명은 다음 순서로 준비한다.

1. **강점과 사실 근거:** 어떤 자원·역량이며 무엇으로 확인했는가?
2. **교재 요소:** 어떤 모방불가능성 요소로 설명할 수 있는가?
3. **모방이 어려운 이유:** 경쟁자가 자금을 투입하거나 인력을 채용해도 쉽게 재현하지 못하는 이유는 무엇인가?
4. **경쟁력과의 연결:** 그 장벽이 비용·차별화 등에서 어떤 효과를 유지하게 하는가?
5. **한계:** 다른 기술·방식으로 대체하거나 추격할 가능성은 없는가?

문장 틀: “이 기업의 [강점]은 [자료로 확인한 사실]에 기반한다. 교재의 [요소, 해당 쪽]로 보면 [축적·관계·원인 불명확성 등] 때문에 경쟁자의 단기간 재현이 어렵다. 따라서 [효과]에 기여할 수 있다. 다만 [대체·추격 가능성]은 검토해야 한다.”

이 문장 틀은 작성 보조용이며, 실제 근거를 채우기 전에는 제출용 설명이 아니다.

### 6단계: 논술형 원고 구성

다음은 **분량 배분 제안**이다. PDF가 세부 배분을 지정한 것은 아니다. 표지·목차·참고문헌의 분량 포함 여부를 확인한 뒤 조정한다.

| 구간 | 담을 내용 | 배분 예시 |
| --- | --- | --- |
| 서론 | 분석 목적, 기업 3개 선정 이유, 시장 범위·시점 | 약 0.5쪽 |
| 본론 | 기업별 VRIO 표와 설명, 기업별 모방불가능성 2개 이상 | 약 2.5쪽 |
| 결론 | 세 기업의 공통점·차이점, 우위의 조건과 분석 한계 | 약 0.5쪽 |
| 목차·참고문헌 등 | 본문에서 사용한 자료와 요구되는 표기 | 약 0.5쪽 |

표가 많아 분량이 넘으면 중복 설명을 줄이고 표의 근거를 간결하게 요약한다. 지정된 11pt를 임의로 줄여 맞추지 않는다.

## 3. 제출 전 체크리스트

- [ ] 수강 학기와 과제 공지가 이 PDF와 일치하는지 확인했다.
- [ ] 글로벌 자동차 제조 산업의 경쟁기업 3개를 선정했다.
- [ ] 기업별 강점이 5개 이상이며 총 15개 이상이다.
- [ ] 모든 강점에 대한 VRIO 분석표와 판단 근거가 있다.
- [ ] I의 판정 방향을 일관되게 사용했다.
- [ ] 기업마다 최소 2개, 총 6개 이상의 강점에 모방불가능성 설명이 있다.
- [ ] 설명에 교재의 요소를 적용했고 용어·쪽수를 확인했다.
- [ ] 서론-본론-결론의 논술형 구성을 갖췄다.
- [ ] 목차와 참고문헌을 준비하고 본문 인용과 참고문헌을 대응시켰다.
- [ ] 기업의 사실 자료와 본인의 분석을 구분했다.
- [ ] 생성형 AI 사용 범위와 출처 표기 요건을 확인하고 반영했다.
- [ ] 아래한글 또는 Word에서 11pt, 줄간격 160%, A4 4매 내외 조건을 점검했다.
- [ ] 제출 기한·경로·파일 형식·파일명을 별도 공지에서 확인했다.
- [ ] 최종 문서를 열어 표 잘림, 페이지 넘김, 출처 누락을 확인했다.
